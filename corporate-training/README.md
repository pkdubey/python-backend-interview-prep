## 🧠 Teaching Philosophy

> **"Why before How"** — Corporate learners need business context, not just syntax.

1. **Analogy-First:** Every concept gets a real-world analogy before code
2. **Show, Don't Tell:** Every 1-hour block = 1 live demo or diagram
3. **War Stories:** "In my moderation project at work, we faced this exact problem..."
4. **No Jargon Without Explanation:** If you say "embedding", explain it in plain English first
5. **Project-Based:** Every day ends with something they built themselves
