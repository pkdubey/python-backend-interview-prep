# Day 13 — Prompt Battle ⚔️ (0.2 day — ~1.5 hours)
**Vibe:** "Gamification, competition, and fun — the best way to cement learning."

---

## 🗣️ How to Open This Day

> "Alright, we've been learning for 12 days. Today we compete. This is the Prompt Battle — a bracket-style competition. The person who gets the AI to produce the best output with the fewest, most clever prompts wins. There's a prize. Let's go."

---

## 🏆 Format

**Duration:** 1.5 hours  
**Teams:** Individual or pairs (depending on class size)  
**Rounds:** 3 rounds, elimination style  
**Prize:** Amazon voucher / certificate / anything fun

---

## 📋 Round Structure

### Round 1 — Warm Up (20 mins)
**Task:** "Get the AI to write a professional email declining a job offer, but in a way that keeps the door open for future opportunities."

**Judging criteria:**
- Is the email professional? (1-5)
- Does it keep the door open? (1-5)
- How many prompts did it take? (fewer = better)

### Round 2 — Technical (25 mins)
**Task:** "Get the AI to write a Python function that:
- Takes a list of employee dictionaries
- Returns the top 3 earners per department
- Handles edge cases (empty list, missing keys)
- Includes docstring and type hints"

**Judging criteria:**
- Does the code actually run? (pass/fail)
- Are edge cases handled? (1-5)
- Code quality (1-5)
- Number of prompts used

### Round 3 — Final (30 mins)
**Task:** "Build a complete prompt system for a 'Customer Support Bot' for an e-commerce company. It should:
- Handle returns, refunds, order tracking
- Escalate to human when needed
- Never be rude, even to angry customers
- Respond in the same language as the customer"

**Judging criteria:**
- Handles all 4 scenarios correctly
- Tone and professionalism
- Language switching works
- Escalation logic

---

## 🎯 Trainer Tips

1. **Be the judge** — or pick 2 students as judges
2. **Show the winning prompt** — explain WHY it worked
3. **Common mistakes to highlight:**
   - Vague prompts ("write a good email" vs "write a 3-paragraph professional email")
   - No format instructions
   - Not specifying the audience
   - Forgetting edge cases
4. **Debrief after each round** — "What made the winning prompt better?"

---

## 📝 Key Lessons to Reinforce

After the battle, summarize:

1. **Specificity wins** — The more specific your prompt, the better the output
2. **Format matters** — Tell the AI exactly what format you want
3. **Examples help** — Few-shot always beats zero-shot for complex tasks
4. **Constraints are good** — "Under 100 words", "3 bullet points", "no jargon"
5. **Iteration is normal** — Even experts refine prompts 3-5 times
